## 1. 版本与换版说明

- 小学、初中教材依据《义务教育数学课程标准（2022 年版）》修订，2024 年秋季起从一年级、
  七年级开始逐年换版；换版过渡期内新旧版并存。分类前先确认学生实际使用的教材年份与册次。
- 高中为 2019 版新教材：人教版含必修第一/二册、选择性必修第一/二/三册；湘教版含必修
  第一/二册、选择性必修第一/二册。
- 本文件列出当前稳定目录，并对已核实的修订版册次加注「2024 修订」。未覆盖的细微版本差异
  通过 `library/taxonomy.override.yaml` 修正。

## 2. 题型、难度受控词表

- 作答形式：选择题（single 单选 / multiple 多选）、填空题、判断题、计算题、证明题、解答题、
  作图题、应用题、阅读理解题、综合题、变式题。
- 定位标签：基础题、中档题、压轴题、拔高题、易错题、真题（中考 / 高考 / 会考）、模拟题。
- 难度 difficulty：1 基础识记、2 基础运用、3 综合运用、4 较难综合、5 压轴/竞赛。
- 考查层级：了解、理解、掌握、综合运用。
